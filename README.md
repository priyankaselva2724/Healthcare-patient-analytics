Healthcare Patient Analytics Dashboard
Project Overview

End-to-end data analytics project analyzing 55,500 hospital patient records from 2019–2024. Built using Python, MySQL, and Power BI.

Dataset
55,500 patient records
Data cleaning and preprocessing using Python
Feature engineering and exploratory analysis
Multiple healthcare metrics including admissions, billing, insurance, and medical conditions

Key Findings
Admissions increased significantly between 2019 and 2020
Obesity showed one of the highest average billing amounts
Test result patterns revealed important billing differences
Data quality issues were identified and corrected
Analytics revealed distinct patient cost segments
